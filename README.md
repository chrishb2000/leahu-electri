# Leahu Electri Service - Professional Website

## Project Overview
A professional multilingual website for Leahu Electri Service, a Chicago-based electrical services company with 20+ years of experience.

## Website Structure

### HTML Files
- **index-en.html** - English version (default language)
- **index-es.html** - Spanish version
- **index-ro.html** - Romanian version

### CSS & JavaScript
- **style.css** - Professional responsive styling with modern effects
- **script.js** - Interactive functionality (carousel, modals, language switching)

### Assets
- **images/** - Renamed SEO-optimized images and videos

## Features Implemented

### ✅ Development Requirements
1. **Multi-language Support**
   - English, Spanish, and Romanian versions
   - Language switcher buttons in navigation (minimalista y simple)
   - Integrated i18n system for dynamic content

2. **Carousel/Slider**
   - Modern CSS transitions and fade effects
   - Auto-rotating carousel (5-second intervals)
   - Manual navigation with previous/next buttons
   - Dot indicators for slide selection

3. **Image Optimization**
   - All images renamed with SEO-friendly names (electrical-service-##)
   - Metadata included for better search engine positioning
   - Optimized file structure

4. **Multi-language Metadata**
   - SEO meta tags for English, Spanish, and Romanian
   - Open Graph tags for social sharing
   - Language-specific keywords

5. **No Contact Form**
   - Removed as per requirements
   - WhatsApp button for direct messaging instead

6. **Scroll-to-Top & WhatsApp Buttons**
   - Fixed "Back to Top" button (bottom-right)
   - Fixed WhatsApp contact button in hero section
   - Both with smooth animations

7. **Social Media Integration**
   - Footer with Facebook, Instagram, WhatsApp links
   - Company contact information

8. **Navigation Menu**
   - Home (Inicio/Acasă)
   - About Us (Quiénes Somos/Despre Noi)
   - Services (Servicios/Servicii)
   - Portfolio (Portafolio/Portofoliu)
   - Contact (Contacto/Contact)

9. **Google Maps Integration**
   - Embedded map showing business location
   - Address: 2847 W Division St, Chicago, IL 60647

10. **Portfolio Gallery**
    - Image grid with hover effects
    - Click to open full-size modal view
    - Videos with auto-play, muted, and loop settings
    - Smooth zoom animations

11. **Company Logo**
    - Logo displayed in navigation bar
    - Professional circular styling with border

12. **Video Support**
    - Auto-playing videos (no audio, looping)
    - Mobile-optimized playback
    - Responsive sizing

## How to Use

### Opening the Website
1. For English version: Open `index-en.html` in a browser
2. For Spanish version: Open `index-es.html` in a browser
3. For Romanian version: Open `index-ro.html` in a browser

### Language Switching
- Click language buttons (EN, ES, RO) in the top-right navigation
- Website will load the appropriate language version

### Portfolio
- Click any portfolio image or video to view in fullscreen modal
- Click the X button or press Escape to close

### Navigation
- Smooth scroll to sections when clicking navigation menu
- Back-to-Top button appears after scrolling down
- WhatsApp button for direct contact
